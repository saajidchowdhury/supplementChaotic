# supplementChaotic

Figures, data, and code for our paper "[Parallels between chaotic scattering and heating in cold ion-atom collisions](https://journals.aps.org/pra/abstract/10.1103/zh5z-hhck)", also on arxiv [here](https://arxiv.org/abs/2509.15117). 

Raw data for figures 1 and 2 available here: [https://drive.google.com/file/d/1RlbhwrKO6i3cNzqbSSEJl6S4toMGGBeI/view?usp=sharing](https://drive.google.com/file/d/1RlbhwrKO6i3cNzqbSSEJl6S4toMGGBeI/view?usp=sharing).
